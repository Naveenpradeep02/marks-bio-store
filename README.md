# Marks Bio Store

Marks Biotech website and product store workspace.

## Projects

- `marksboiteck-website/` — React storefront built with Vite.
- `Admin/` — Administration application.
- `Backend/` — Express API with MySQL storage and product image uploads.

## Local development

Install dependencies in each application directory with `npm install`.
Configure the required environment variables locally before starting the apps.

Start the storefront:

```sh
cd marksboiteck-website
npm run dev
```

Start the API in another terminal:

```sh
cd Backend
npm run dev
```

Build the storefront with `npm run build` from `marksboiteck-website/`.
